Notes

IELTS Speaking Masterclass: Could not be tested via automated headless browser — the page loads large audio files (TTS narration) and dependencies that prevent navigation within 60s. The course is designed as a SCORM 2004 4th Edition package for LMS deployment and has its own internal WCAG considerations (keyboard navigation, focus management, screen reader support for the voice recorder).
Third-Party Content: The Learning Analytics Dashboard embeds a dashboard from Veracity LRS, which renders amCharts SVGs and MUI components. These are third-party rendered elements and cannot be modified from our code. The host page (iframe container, theme toggle, back button) passes all checks.

Fixes Applied

The following accessibility issues were identified during the audit and have been fixed:

  • Color contrast — Darkened --text-light and --text-muted CSS variables across all pages to meet 4.5:1 minimum contrast ratio against glass backgrounds.
  • Dark mode badge contrast — Updated .compliant-badge, .course-badge, and .intro-badge for Sufficient contrast in dark mode.
  • Dark mode backgrounds — Fixed .scenario-setup and .learner-banner which did not switch to dark backgrounds in dark mode.
  • Theme toggle visibility — Made the theme toggle button visible in light mode on subpages (previously used transparent styles inherited from dark-only context).
  • H5P iframe title — Added MutationObserver to dynamically set title attribute on H5P-generated iframes for screen readers.
  • Inline style overrides — Fixed #skipNameBtn and other elements with hardcoded inline styles that prevented dark mode color switching.

Methodology

Each page was tested using axe-core 4.11 via Puppeteer running in a headless Chromium browser. Tests were run at 1280×720 viewport on both light and dark themes. The audit covered WCAG 2.0 Level A and AA, plus WCAG 2.1 Level A and AA success criteria.

  • Pages were loaded with a 30s timeout (60s for IELTS Masterclass).
  • The theme was toggled via JavaScript before each test run.
  • Results include both violations (confirmed failures) and incomplete (needs manual review).
