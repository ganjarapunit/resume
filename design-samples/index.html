🎨 Portfolio Design Concepts

4 distinct visual directions for Punit Ganjara's Learning Experience Design portfolio — all WCAG AA/AAA compliant with high-contrast colors, dark mode, and responsive layouts.

Concept 01
Sidebar Dashboard
Fixed sidebar with expandable category groups (H5P, SCORM, xAPI, Reports) + project cards grid + featured spotlight banner. Clean, professional, navigation-heavy.
Sidebar navExpandable sublinksCard gridSpotlight
Best for: Lots of projects that need sub-categorization. Familiar LMS-like sidebar navigation.
