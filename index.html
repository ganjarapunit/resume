Adapt Framework (open-source game changer)

I took the Adapt Framework — a free, open-source HTML5 eLearning authoring framework — and wrapped production courses into four LMS packaging formats: SCORM 1.2, SCORM 2004 4th Ed., xAPI, and cmi5 — each verified against real LMS tooling and LRS endpoints.

The Adapt Framework xAPI Course demonstrates responsive multi-device design, WCAG AA accessibility, step locking, bookmarking, assessment with question banks, and full xAPI statement tracking to the Veracity LRS. The LXD Design Frameworks branching scenario explores real-world LXD decisions — framework selection, learner analysis, evaluation strategy, and ROI — all within an accessible, standards-compliant Adapt course.
