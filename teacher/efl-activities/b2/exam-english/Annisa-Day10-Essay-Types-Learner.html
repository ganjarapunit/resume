3 types

Words DONE

Look at the signal words first.

‘Argue’, ‘agree’ or ‘prove’ is which type?
‘Explain’, ‘describe’ or ‘how’ is which type?
‘Both views’ plus ‘I’ is which type?
Same PEEL works inside all three.
Model matching: argue, agree or prove points to Argument. Explain, describe or how points to Expository. Both views plus I points to Discussion.

Match 3

Core DONE

3 introductions, 3 types.

A I strongly agree that classrooms are better because interaction is stronger.
B This essay will explain how recorded lessons help students review.
C While some want homework banned, others support it, and I support short homework.
What type is A?
What type is B?
What type is C?
Signals: ‘I argue’, ‘This essay will’, ‘While’ plus ‘I’.
Model: A is Argument, I strongly agree that classrooms are better. B is Expository, This essay will explain how recorded lessons help students review. C is Discussion, While some want ban, others support help, and I support short homework.
