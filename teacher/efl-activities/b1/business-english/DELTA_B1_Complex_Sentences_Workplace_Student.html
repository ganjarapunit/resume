Find the linking words

6 minutes • Choose although / because / when / while / if / unless / even though / so that

Choose the linking word

One word is extra. Use each word once.

we started early, we are behind the client changed requirements.
we met last Tuesday, we agreed to send the draft the manager could review it.
we don't receive the data, we won't finish on time.
we receive feedback by tomorrow, we will have to decide without the client.
I was checking the budget, I noticed we spent too much.
we had problems, I am optimistic we support each other.
Answer key
  • 1. Although … because
  • 2. When … so that
  • 3. If
  • 4. Unless (= if we do NOT receive)
  • 5. While
  • 6. Even though … if

Choose who / which / that

Answer key

  • 2. that — thing, no commas
  • 3. which — thing, with commas
  • 4. who — person, with commas

Answer key — model answers
  1. Although Tom is quite busy, he will help us because he understands how important the client is.
  2. We have to stay within the limit that the finance team set.
  3. Now that we have a clear plan, I feel much more confident that we will succeed.
  4. Although they started early, they are behind schedule because the client changed the requirements.
  5. We will contact IT again so that we can stay organised. / So that we can stay organised, we will contact IT again.

Your sentence can be a little different. Check: one main clause + one subordinate clause, correct linking word, comma after fronted clause.

Speak and write — Your workplace challenge

15 minutes • Speaking: 60–90 sec • Writing: 80–120 words

Speak first, then write. Use 3 complex sentences.

Choose one: a recent project delay / a busy week / a plan with colleagues. Use although/because, if/unless, so that/now that/before, who/which/that.

Sentence starters — use 3:
  • Although ... , ... because ...
  • If / Unless ... , ... which ...
  • ... so that ... / While I was ..., I ...
  • ... who / which / that ...
Example: “Although we started early, we were behind schedule because the client changed requirements. If we don't get the data that IT promised, we won't finish, which is risky, so that is why I need to contact them tomorrow.”
